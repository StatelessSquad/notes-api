# ADR-0001: Choose Python 3.12 + FastAPI + SQLModel on SQLite for notes-api

## Status
Accepted

## Context
We need to build a tiny personal notes service with CRUD endpoints and a health check. The service should be simple to develop, deploy, and maintain.

## Decision
We chose Python 3.12 as the runtime, FastAPI for the web framework, SQLModel for ORM, and SQLite for the database.

## Consequences
- Pros: Fast development, automatic API docs, minimal deployment footprint, SQLite requires no external service.
- Cons: SQLite not suitable for high write concurrency; if scaling needed, migrate to PostgreSQL.
